A map of the methods

Choose a way to estimate the treatment effect

S asks one model about each schedule. T asks a separate model for each. Both predict two risks for the same patient profile.

X starts with T’s two risk fits, then combines observed outcomes and opposite-schedule predictions to learn how effects vary. R learns from residuals.

Inverse probability weighting gives more weight to patients whose observed schedule was less likely, adjusting which patients each arm represents.

AIPW corrects an initial estimate with weighted residuals. TMLE updates the outcome predictions before averaging. Both use a treatment model as well.
