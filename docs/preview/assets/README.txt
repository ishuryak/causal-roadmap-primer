CONTEXT AND CONFOUNDING SKETCH

context-confounding.svg is the illustration displayed in step 2. It extends
the primer's pencil-and-ink style with an explicit common-cause diagram.
Labels and arrows remain editable vector elements.

context-confounding.drawio is a native editable diagram with separate nodes,
labels and connected arrows. Open it in diagrams.net. To use a revised version
on the site, choose File > Export as > SVG, retain a readable viewBox and text,
and replace context-confounding.svg. Keep the three arrow directions and the
image's descriptive title/alt text consistent with the accompanying argument.

The diagrams represent proposed assumptions, not estimated causal effects.
